# 功能完善与验收记录：v2.2.0 / 用户端 v1.2.0

日期：2026-10-27。本轮在本机真实 MySQL、Redis、后端和 81 端口代理上排查、修改、验收，未重置数据库。

## 新增功能

- 商品收藏：详情页收藏/取消、个人中心收藏分页、跨账号隔离、重复收藏幂等、下架商品保留与移除。公开返回不包含成本价。
- 站内通知偏好：分别保存订单与系统提醒开关；事件落库时读取偏好，关闭后不产生对应后续消息，已有消息保留。
- 登录设备管理：会话客户端、登录时间、到期时间、当前设备标记；退出某个其他会话、退出其他全部会话。列表使用独立不透明会话编号，不返回登录 Token。
- 修改联系手机号：校验当前密码、格式与唯一性；修改成功使全部会话失效。仅保存联系信息，尚未接入短信归属验证，不用于找回密码。

## 本轮修复

1. 地址快照原字段为 id，删除保护却按 addressId 文本匹配：改为 JSON 精确比较，同时兼容历史 id，避免错误删除与 ID 前缀误判。
2. 默认地址并发冲突：会员行锁串行化本人的地址写操作；按已有地址主键清除默认标记，避免不同新会员首个地址的范围锁死锁。禁止直接取消当前默认而不指定替代地址。
3. 立即购买累加购物车数量：按本次所选数量覆盖对应行，重新同步宠物关联；不再先累加导致库存误报。
4. 同一 clientToken 并发下单：先锁会员行，再检查原结果；12 次同时请求只生成一单、扣一次库存。
5. 已归档宠物仍可绑定加购/下单：后端拒绝，购物车显示原因并允许取消关联，即使没有活动宠物也有解绑入口。
6. 支付成功后失败/超时回调覆盖状态、重复成功产生多条支付记录：订单行锁与状态/到期校验；已支付返回原成功记录；新幂等键通过请求映射持久化，跨订单或不同金额/渠道/结果复用键会拒绝。
7. 后台手工调整库存写入 null 订单号导致失败：手工流水生成独立 ADJ 参考号，支持连续多次调整。
8. 并发库存流水前后数量不准确、手工调整竞争：SKU 行锁保护读取、修改、记流水，验证不同会员同时购买和取消后的逐笔数量。
9. 修改密码与旧密码登录的竞争：登录及密码更新使用同一会员行锁；请求鉴权再次确认会员正常状态。
10. 本机内存不足时误报未找到 JDK：轻量版本探测；后端默认堆调整为 128–512MB，Maven 默认 32–384MB，可用现有 MAVEN_OPTS 覆盖构建参数。
11. 开着旧页面重新构建后，动态资源哈希失效：路由捕获资源加载错误，60 秒内最多重新加载一次目标页面，失败时提示重试。

## 验收结果与复现

在 user-ui 目录运行，需本机服务启动、config/backend.env 可用。接口测试会新建带测试前缀的虚拟账号、商品与订单；沙箱成功订单保留用于追溯，测试商品最终下架。不会重置现有数据。

- `node scripts/member-features-integration.mjs`：111 项接口检查，覆盖收藏、偏好、默认地址、重复下单、支付回调、归档宠物、会话撤销、手机号、隔离与持久化。
- `node scripts/admin-flow-integration.mjs`：62 项检查，商家创建 → 驳回 → 重提 → 审核通过 → 上架 → 库存连续调整；审核员与商家权限；外商户隔离；会员禁用/恢复；6 个不同会员同时购买再取消，库存流水前后数量完整。
- `node scripts/integration.mjs`：原用户端 53 项真实接口检查。
- `node scripts/repair-integration.mjs`：原修复 50 项检查，包括自动超时关单、自动确认收货、地址修改、回调键冲突、密码改后会话失效和离线上游 503。
- `node scripts/stock-concurrency.mjs`：专用库存 1 商品，20 次请求，1 成功、19 库存不足；取消后恢复为 1。
- `node scripts/verify-runtime-db.mjs`：运行库 8 项只读检查全部 PASS。
- `npm run check`：19 页面、59 Vue 文件编译检查通过；`npm test`：5 项契约测试通过；`npm run build`：生产构建通过；后端 Maven 编译打包成功。
- 浏览器实测：收藏状态与列表刷新保留；下架商品提示；通知偏好真实回显；会话列表与安全表单；原购物车 2 件时立即购买 1 件，结算明确显示 ×1，未提交真实订单。截图在 `verify/member-features/`。

## 交付边界

这些结果证明上述本机环境与用例通过，不代表所有环境与输入都无故障。真实支付、短信验证/找回密码、账号注销、优惠券、订阅扣款、售后工单、发票、多商户拆单、处方资质和社区仍不属于已实现能力。支付渠道名称仅作沙箱分支演示。

设备名称取浏览器 User-Agent，不是硬件指纹；当前会话管理沿用 Redis 键扫描方式，大规模生产使用前应改为会员会话索引。通知偏好控制站内事件提醒，未提供短信/邮件推送，也未新增后台群发入口。商品缺少真实图片时显示明确的缺图插画。未进行生产压力测试、第三方支付联调或全浏览器矩阵验收。
