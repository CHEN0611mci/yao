# 2026-10-27 整体核查及一期修复

## 范围与故障原因

核查一期商城用户端、商城后端、管理端、启动和交付。原详细设计把大量后端缺口作为前端兜底，本次对主流程直接补充后端。二期商业能力不在本轮实现范围。

截图故障发生在本机：81/8080/3306/6379 当时均未监听，MySQL/Redis 计划任务未运行。原启动入口只启动 Vite，没有后端健康检查。本次恢复真实服务并修复入口，没有重置数据库。

## 修复和新增

- 健康检查真实查询数据库及 Redis；一键启动已安装依赖、后端和用户端；JSON 503 明确启动方式；源码更新自动重建，安全停止本项目旧进程。
- 分类查询在 PageHelper 开启前完成，修复用户/管理/商家分页；有货与指定宠物筛选；用户端不暴露成本价。
- 禁售词校验、一期处方商品禁止购买、单笔金额与单品数量限制。
- 原密码验证、修改密码、全部会员会话失效；错误原密码和重复新密码拒绝。
- 购物车宠物解绑、按宠查看、清理失效、批量移除所选；搜索历史删除和清空。
- 宠物归档列表、恢复、导出；恢复时检查活跃数量上限。
- 订单号/商品名搜索、发货前改本人地址、再次购买按当前价格库存校验；已发货/关闭禁止改址。
- 自动超时关单、库存仅回滚一次、过期订单拒绝支付、自动确认收货及消息。
- 相同物流重复发货返回已有结果；支付回调幂等键校验订单和金额归属。
- 首页轮播排期/排序及热词/承诺/客服文案后台参数管理；意见反馈持久化到操作日志。
- 订单明细兼容文本和 JSON 宠物快照；新增弹窗和工具栏适配手机。
