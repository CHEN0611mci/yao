## 10. 启停流程与验证命令

### 10.1 当前手工流程（实测可用）

1. 确认 MySQL 服务：`Get-Service MySQL80`（应为 Running）。
2. 启动 Redis：`C:\Users\LEGION\Documents\Aiwork5\dev-redis\redis-server.exe dev-redis\redis.conf`（或双击 `RedisService.exe` 安装为服务）。
3. 启动后端：IDEA 中运行 `RuoYiApplication`（Project SDK 指定 JDK 17），或安装 Maven 后 `mvn -pl ruoyi-admin spring-boot:run`。
4. 启动管理前端：`cd shop\RuoYi-Vue3-master; npm.cmd run dev`（端口 80）。
5. 启动客户前台（待建）：`cd user-ui; npm.cmd run dev`（端口 81）。

### 10.2 目标一键脚本（交付要求）

```powershell
# deploy/start-all.ps1 建议流程
1. 读取 .env（缺少则提示复制 .env.example）
2. 检查 Java 版本（要求 17，拒绝 25 直接运行）
3. 检查 MySQL 服务状态与 shop 库连通性（SELECT 1）
4. 检查 Redis 6379，未启动则拉起 dev-redis 并等待 ping 成功
5. 检查 8080/80/81 端口占用
6. 启动后端 jar（或提示用 IDEA 启动）
7. 提示启动两个前端
8. 输出访问地址与测试账号
```

```powershell
# deploy/stop-all.ps1 建议流程
1. 停止后端进程（按端口或 PID）
2. 停止 Redis（保留 data/）
3. 不停止 MySQL 服务（避免影响其他库）
```
