## 三、源码包内容说明

`萌宠优选_商城系统_源码与部署脚本_v2.4.0.zip`（解压后根目录 `萌宠优选_商城系统_v2.4.0/`）：

| 目录 / 文件 | 内容 |
|---|---|
| `backend/` | 后端源码（RuoYi 3.9.2 + 商城业务模块 `ruoyi-mall`） |
| `admin-ui/` | 管理端源码（管理员 / 商家 / 审核员，Vue 3 + Vite 6） |
| `user-ui/` | 用户端源码（游客 / 会员，Vue 3 + Vite 6，桌面 + 移动） |
| `db/` | 建库、种子数据、菜单补丁、会员功能升级与校验 SQL |
| `setup/` | 运行期脚本：环境预检、建库、构建、启动、停止、冒烟 |
| `scripts/` | 装机期工具：MySQL / Redis 安装、建库导入、文档配图脚本 |
| `config/backend.env.example` | 后端配置模板（复制为 `backend.env` 后填写本机密码） |
| `*.bat` | 一键启动入口（`start-all.bat` 等）、预检、建库、冒烟、停止 |
| `README.md` / `RUNBOOK.md` / `VERSION.txt` | 从零部署的四步说明、排错手册、版本说明 |

**未打包内容**（避免臃肿与信息泄露）：`node_modules`、`target` / `dist` 构建产物、`*.jar`、`.env` 与 `config/backend.env`（含本机密码）、日志、`data/`、运行数据、`.git`、本机截图与课程素材。

**解压后快速启动**（Windows，需 JDK 17、MySQL 8、Redis 7、Node 18+）：

```powershell
cd 萌宠优选_商城系统_v2.4.0
.\check-env.bat       # 环境预检
.\init-db.bat         # 初始化 shop 数据库（已有库走增量升级，不重置数据）
.\start-all.bat       # 同时启动：用户端 81 + 管理端 80（后端 8080）
.\smoke-test.bat      # 冒烟验收（期望 PASS=30 FAIL=0）
```
